# Clean-Room Boundary

This repository is intentionally a **reconstruction, not an export**.

## Excluded

The repository contains no:

- employer or customer names
- internal application names
- production source code
- copied database schemas
- real table, column, file, or directory names
- source-system URLs
- vendor or customer identifiers
- production data or screenshots
- credentials, tokens, or configuration secrets
- internal ticket numbers or documentation
- proprietary fee, pricing, forecasting, or business rules

## Included

The repository includes only generalized engineering ideas and new code written for this portfolio, including:

- orchestration semantics
- run/step telemetry
- source coverage classification
- freshness evaluation
- input idempotency
- interrupted-run recovery
- integrity reconciliation
- synthetic examples and tests

## Sanitization rule

When there is doubt whether a detail communicates engineering skill or merely reveals private implementation context, the detail is omitted.

The public project should be able to stand on its own without access to the original private system.
